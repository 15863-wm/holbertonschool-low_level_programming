# C - Function pointers

This directory contains C programs about function pointers.

## Files

| File | Description |
|------|-------------|
| 0-print_name.c | Function that prints a name using a function pointer passed as argument. |
| function_pointers.h | Header file with the function prototypes. |

## Compilation

Compiled with: gcc -Wall -pedantic -Werror -Wextra -std=gnu89
